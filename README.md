# React Educational Platform 🎓

A responsive educational platform built with **React.js** for presenting and managing educational content such as courses and articles.

## ✨ Features

* 🏠 Home page
* 📚 Courses section
* 📝 Articles section
* 🔐 Login and authentication
* 🛡️ Protected routes with `PrivateRoute`
* ➕ Add new articles
* ✏️ Edit articles
* ⚙️ User settings and panel
* 🧭 Navigation between pages using React Router
* 🧩 Reusable React components
* 📱 Responsive user interface
* 🗂️ Custom local data management using `db.json`

## 🛠️ Technologies

* **React.js**
* **JavaScript (ES6+)**
* **React Router**
* **HTML5**
* **CSS3**
* **JSON**
* **Git & GitHub**

## 📦 Local Data

The project includes a custom `db.json` file created specifically for this application.

The file is used as the project's local data source and contains the information required by different parts of the application, such as educational content and articles.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Sevda81/react-project.git
```

Go to the project directory:

```bash
cd react-project
```

Install dependencies:

```bash
npm install
```

Start the React development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```
